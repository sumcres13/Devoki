# Satkar Morishita website

Four-page Japanese / English static website for Deuki International LLC and its Indian restaurant and bar, Satkar Morishita.

## Open locally

Open `index.html` in a browser, or run `python -m http.server 8088` from this folder and visit http://localhost:8088/.

## Pages

- `index.html`: Restaurant introduction, featured food and Facebook link.
- `about.html`: Managing member's message and company information.
- `stores.html`: Store description, hours, address, phone, photos, and map.
- `reservation.html`: Tabelog, Gurunavi, phone, and delivery links.

The language switch remembers the visitor's choice in local storage. The map and Google Fonts require an internet connection. Reservation and delivery links open the supplied third-party listings; the site does not process reservations itself.

## Files

Upload the four HTML pages, `styles.css`, `script.js`, and the `assets/` folder together. Open `index.html` as the entry page. No build or package installation is required.
