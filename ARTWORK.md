# Image assets

The site uses the restaurant logo and five photographs supplied for Satkar Morishita:

- `assets/satkar-logo.png` — shop logo
- `assets/satkar-food-hero.png` — food hero image
- `assets/satkar-exterior.png` — storefront
- `assets/satkar-interior-1.png` and `assets/satkar-interior-2.png` — dining room gallery
- `assets/deuki-ceo.png` — representative director portrait

Delivery service and restaurant listing logos are retained from the supplied website template.

The approved values section uses `assets/values-culinary-bg-v2.png`, generated during the website editing work. The gallery uses original minimal SVG culinary drawings: `gallery-curry-bowl.svg`, `gallery-herb-sprig.svg`, `gallery-chilli-pods.svg`, and `gallery-mortar-spice.svg`. Their matching SVG data URLs are embedded in the final gallery CSS rules.

Other supplied and earlier artwork files remain in `assets/` to preserve the complete source collection. Some are not used by the current layout. Retain image bytes, dimensions, filenames, and transparency when importing the repository.
